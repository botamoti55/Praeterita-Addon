# 未来の保管庫：チェスト式回収UI（Issue #12）

> **v0.2.6導入・v0.2.7維持の仕様書。** コードとRPのUI定義（9列×6行、上45枠＋下9枠）、選択・解除・確定・キャンセル・ページ切替の静的確認を行いました。実際のMinecraftでの表示・操作は未確認です。導入はバックアップ済みのテストワールドから。

## 何が変わったか

未来の断片・未来の欠片・未来の結晶・未来の大結晶を使用すると、**9列×6行（54マス）のチェスト風画面**で失ったアイテムを一覧できます。上45マスに保管品を並べ、最下段9マスは操作エリアです。保管品が45枠を超える場合はページ送りで選びます。

- アイテム枠をクリック／タップ → **選択状態に切り替え**。選択済みは緑のマーカーで表示。
- 同じ枠をもう一度押す → 選択解除。
- 右下付近の**回収確定**を押してはじめて保管庫から移動し、結晶を**1個だけ消費**します。
- **キャンセル**なら保管品も結晶も変化しません。
- 従来の「古いものから自動回収」も最下段に残しています。

| 使用する未来アイテム | 一度に回収できる最大枠数 |
| --- | ---: |
| 未来の断片 | 3枠 |
| 未来の欠片 | 9枠 |
| 未来の結晶 | 15枠 |
| 未来の大結晶 | 27枠 |

※「枠」はスタック数。64個のスタックも1枠です。既存の未来保管庫をまたいで選択可能です。装備や左手の復帰先も従来仕様を保持します。

## チェスト「風」である理由

Minecraftの `@minecraft/server-ui` にはネイティブなチェストメニューがありません。今回の実装は `ActionFormData` に専用RPのJSON UIを組み合わせて**チェストのマス目の外観**を作ります。実際のチェストをワールドに置かず、アイテムをゲーム内の仮チェストへ一時複製することもありません。

- 本物のチェストのようにドラッグ＆ドロップして移すUIではありません。
- RPの `ui/server_form.json` はUIの共通定義を置き換えるため、**他のUI変更アドオンと競合する可能性**があります。
- 現時点で構文・JSON・模擬選択操作は検査済みですが、**スマホ版・Windows版・BDSの実機表示は未検証**です。

## 回収の安全性

回収の前に、選んだ元枠・アイテム種類・個数・回収先の空きを再検査します。結晶スタックが2個以上の場合も回収1回で消費するのは**1個**です。途中で一部回収した後に失敗した場合は、増殖防止のため結晶を返却しません。データのバックアップを取ってください。

## 絶対変更禁止

[AGENTS.md](../AGENTS.md) に定義されたスノードームの持ち方（一人称／三人称の回転・位置・倍率、root pivot）はこの更新で変更しません。表示用JSONやモデルの新規調整もしません。

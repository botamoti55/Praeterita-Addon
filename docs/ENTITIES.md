[図鑑トップ](README.md) / [アイテム](ITEMS.md) / [装備](EQUIPMENT.md) / [クラフト](CRAFTING.md)

> 現行BPに定義されている**独自エンティティは2種類**です。「過去へ送る魔法弾」は専用の新規エンティティではなく、既存の雪球エンティティに識別情報を付けて使用しています。

## 未来を売る者

- **内部ID**：`praeteria:future_merchant`
- **性格**：普段は取引に応じ、攻撃されると反撃する**中立モブ**
- **最大HP**：**100**
- **近接攻撃力**：定義値 **15**
- **装備**：時流の剣を持たせる処理あり（実機表示は要確認）。**倒してもこの剣そのものは通常のドロップ対象ではありません**。
- **出現**：オーバーワールドのプレイヤー付近にランダム出現する仕組み。既に近くに商人がいるときは重複出現を抑制。タイマーによる退場処理あり。

### 戦闘・時間魔法

商人を攻撃すると、殴りで反撃し、距離がある相手には時間魔法弾を放ちます。

- **近接攻撃の命中時**：ダメージに加えて約**30秒の時間追放**を付与（Issue #2）。
- **遠距離**：追尾対象に向けて時間魔法の雪球を射出。命中相手に同様の時間追放効果。
- プレイヤーの追放時は**一時スペクテイター化・移動/視点入力の制限・不可視**を適用し、解除時に元の状態へ戻す処理があります。
- モブには不可視、最大級の鈍足、弱体化を与えます。Minecraft実機での特殊攻撃・AIの完全停止は保証されません。

**第1抽選：以下から最大1種類**を選びます。

| ドロップ | 確率 |
| --- | ---: |
| 未来の断片 | 30％ |
| 未来の欠片 | 20％ |
| 未来の結晶 | 10％ |
| 未来の大結晶 | 5％ |

## 封じられた未来（保管庫エンティティ）

- **内部ID**：`praeteria:future_vault`
- **役割**：時間帰還の際に預かったアイテムを非公開領域で保管する内部エンティティ。
- **外見/操作**：プレイヤーが通常の敵や商人のように扱う存在ではありません。取引・回収フォームから間接的に利用します。
- **収納**：**1体あたり27枠**。通常インベントリ用と、ホットバー4〜9・防具・左手用の保管庫を複数組み合わせることで、1回の帰還につき最大38枠を扱います。
- **管理**：所有プレイヤー、保存世代、保管枠の種類などを内部プロパティで区別。中身が空になれば不要な保管庫を整理します。
- **永続性**：専用のチャンク読み込み・エンティティ永続化を利用しますが、BDSのバックアップ・復元・バージョン間互換性は別途検証が必要です。

**注意**：保管庫エンティティを手動削除すると、まだ取り戻していないアイテムが失われる可能性があります。

## 独自IDではない関連エンティティ

- **時間魔法弾**：`minecraft:snowball`。スクリプトが識別プロパティを付与し、衝突時に時間追放を実行します。
- **時間停止の境界表示**：粒子による演出。独立したエンティティは生成しません。
- **巻き戻す通常モブ**：独自モブではなく、記録範囲にいたバニラ等のモブ。復元時に同じ個体を戻すか、消えていた場合は同種を再生成します。個体の全状態は完全復元できません。

# プラエテリタ図鑑

**対象：開発版 v0.2.2（Issue #1〜#3反映）**

この図鑑は、アドオンの配布ZIP内にある**ビヘイビアパックのアイテム・エンティティ・レシピ・スクリプト**を基に作成しています。

| ページ | 内容 |
| --- | --- |
| [アイテム図鑑](ITEMS.md) | スノードーム、未来の回収アイテム、時の欠片、時流インゴット、杖、祝福の刻 |
| [装備・武器・工具](EQUIPMENT.md) | 時駆けるつるはし、時流工具、パクセル、時の王、時流防具、特殊能力 |
| [エンティティ図鑑](ENTITIES.md) | 未来を売る者、封じられた未来、取引、ドロップ、時間魔法 |
| [クラフトレシピ](CRAFTING.md) | 現行BPにある主要クラフトを配置付きで掲載 |

## はじめに

- 公式Minecraftアドオンではなく、**開発中の実験的なBedrockアドオン**です。実機での動作検証が不足している機能もあります。
- アイテムIDは互換性のため `praeteria:` のままです。表示名は「プラエテリタ」です。
- 時間操作・時間追放・未来保管庫・特殊採掘は、ゲームの進行や所持品に影響します。**必ずコピーしたワールドで試してください**。
- 各項目の「○秒」「○％」「耐久値」などはソース上の設定値または目標値であり、Minecraft本体の挙動を全面的に保証するものではありません。

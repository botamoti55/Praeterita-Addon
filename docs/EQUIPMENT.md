| 名前 | ID（`praeteria:` 以下） | 耐久 | 主な機能 |
| --- | --- | ---: | --- |
| 時流のつるはし | `timeflow_pickaxe` | 6,093 | 石系に高速採掘（定義速度240） |
| 時流の斧 | `timeflow_axe` | 6,093 | 木系に高速採掘（120） |
| 時流のシャベル | `timeflow_shovel` | 6,093 | 土・砂系に高速採掘（120） |
| 時流の鍬 | `timeflow_hoe` | **無限** | 農作物の局所加速＋鍬対応ブロックの高速処理（90） |
| 時流の剣 | `timeflow_sword` | 2,031 | 攻撃力18を意図、しゃがみ使用で範囲時間停止 |
| 時流のパクセル | `timeflow_paxel` | 6,093 | つるはし・斧・シャベル・鍬の複合機能＋農業加速 |
| 時の王 | `time_king` | **無限** | 攻撃力25を意図、時間停止＋複合超高速採掘＋農業加速 |

**製作の流れ**：
- 時流インゴットと棒から、つるはし・斧・シャベル・鍬・剣を製作。
- **時流のつるはし＋斧＋シャベル＋鍬** → **時流のパクセル**。
- **時流のパクセル＋時流の剣** → **時の王**。

### 範囲時間停止（時流の剣・時の王）

**しゃがみながら使用**すると、プレイヤーを除く**半径10ブロック以内のモブ**に30秒間の時間停止を適用。再使用まで**45秒**で、剣と「時の王」は同じクールタイムを使います。

- 範囲の境界を粒子のリングで表示（約1秒ごとに更新）。
- 対象モブの位置と向きを固定し、鈍足・弱体化を付与。
- 飛び道具は射手を特定できた場合に除去する方式であり、**全種類の特殊攻撃を100％止められるわけではありません**。
- **通常の剣攻撃で時間追放を付与する旧仕様は、v0.2.1で変更**されました。単体への30秒追放は [時送りの杖](ITEMS.md#時送りの杖) の役割です。

### 農作物の成長加速（鍬・パクセル・時の王）

手に持っている間、プレイヤー中心の**水平半径約6ブロック・高さ±1ブロック**の対応作物を約2秒おきに走査。小麦・ニンジン・ジャガイモ・ビートルート・カボチャ/スイカの茎・ネザーウォート・スイートベリー・カカオなどを対象に、条件が合えば成長段階を追加で進めます。

目標は**通常の約5倍の成長**ですが、農地や明るさの条件によって変わるため、厳密な倍率ではありません。**ワールド全体のランダムティック速度は変更しません**。

### 採掘に関する注意

「石系の即時破壊」「全ブロック高速破壊」は目標仕様ですが、`minecraft:digger` の対象タグとブロック側の仕様に依存します。ゲーム内での瞬間破壊やドロップ条件があらゆるブロックに成立する保証はありません。特に「時の王」で危険なブロックを壊す際はテストワールドを使用してください。

### 時間逆行による蘇生

**条件**：時流防具を1部位以上装備し、インベントリまたは左手に**不死のトーテム**が1個以上ある。被ダメージ後のHPが**2以下**になる見込みのとき、死亡直前に処理を試みます。

| 装備数 | 戻る時刻（目安） |
| --- | --- |
| 1部位 | 2秒前 |
| 2部位 | 4秒前 |
| 3部位 | 6秒前 |
| 4部位 | 8秒前 |

発動すると**トーテム1個消費、体力を全回復、衝撃吸収Vによる追加20HP、短時間の耐性付与**を試みます。位置履歴は約0.25秒ごとに記録され、記録不足時は最古の記録位置などを利用します。

- 所持品を地面へドロップさせてから回収するのではなく、**可能なら致死ダメージそのものをキャンセル**する設計。
- ワールド再起動直後や一部の特殊死亡、他アドオンと同時使用時の蘇生は保証されません。
- 時流防具の見た目用テクスチャと装着用アタッチャブルも存在しますが、実機での描画確認は必要です。

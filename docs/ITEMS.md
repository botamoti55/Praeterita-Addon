## プラエテリタ（時間保存のスノードーム）

| アイテム | ID | 役割 |
| --- | --- | --- |
| プラエテリタの鉄台座 | `praeteria:base` | 鉄インゴット3個で作る中間素材 |
| ダイヤを封じたガラスドーム | `praeteria:dome` | ガラス8個とダイヤ1個で作る中間素材 |
| プラエテリタ（空） | `praeteria:globe_0` | 鉄台座＋ガラスドームで作る、記憶0個の本体 |
| プラエテリタ（記憶 1/5〜5/5） | `praeteria:globe_1`〜`globe_5` | 記憶数に応じて変化する本体 |

**使用方法**：しゃがみ＋使用で過去を記録（不死のトーテム1個を消費）。しゃがみで記録を切り替え、立った状態で使用すると選択中の過去へ帰還します。

- 1個のドームにつき**最大5件**、1件の保存範囲は **32×32×32ブロック**。対象は地形、範囲内のプレイヤーの位置・体力、対応するモブの位置・向き・体力です。
- 帰還には記録に含まれるプレイヤーがオンラインであること等の条件があります。モブの装備・飼育状態などは完全な復元ではありません。
- **帰還時、ホットバーの1〜3番のみ手元に残る**。ホットバー4〜9番（6枠）、通常インベントリ（27枠）、防具4枠と左手1枠は未来の保管庫へ移します。預入対象は最大**38枠**です。
- 帰還した使用者は**保存時のHPを基準に19HP失う**。保存時のHPが19以下なら死亡するため、テストワールドで使用してください。
- 1時間内の繰り返し使用に対する「禁忌」機能があります。閾値に達するとランダムなラテン語の警告音声のあと、オンラインの全プレイヤーを死亡させる危険な挙動です。テスト用の有効・無効切替は付属ファンクションを参照してください。
- 保存したドームの複製や、他人の記録へのアクセスには制限があります。**大切なワールドは必ずバックアップ**してください。

## 未来を取り戻すアイテム

| 名前 | ID | 1回に取り戻せる最大枠数 |
| --- | --- | ---: |
| 未来の断片 | `praeteria:future_fragment` | 3 |
| 未来の欠片 | `praeteria:future_shard` | 9 |
| 未来の結晶 | `praeteria:future_crystal` | 15 |
| 未来の大結晶 | `praeteria:future_great_crystal` | 27 |

未来の商人との取引、または商人の討伐ドロップから入手できます。**数字はアイテム個数ではなく、占有しているインベントリ枠数**です。例えば石64個のスタックは1枠と数えます。

**v0.2.6 / Issue #12以降**：未来の回収アイテムを手に持って使用すると、**チェスト風の9列×6行（54マス）UI**を開きます。上45マスに未回収アイテムが並び、タップ・クリックで選択と解除ができます。下9マスにはページ送り・選択数・回収確定・古いものから自動回収・キャンセルが並びます。45枠を超える保管品はページ切替で表示します。選択は使用する結晶の上限3／9／15／27枠までです。

**選んだだけではアイテムは移動しません。** 回収確定時に選択中のアイテムを返却し、結晶を1回につき1個消費します（スタックで持っていても1個だけ）。キャンセルでは消費しません。マス目をタップして選ぶ**チェスト風フォーム**であり、本物のチェストのようなドラッグ移動ではありません。ほかのUI改造RPとの競合やMinecraft実機での見た目はまだ未検証です。詳細は [未来の保管庫UI仕様](FUTURE_VAULT_UI.md) を参照してください。

- 複数の未来の保管庫を横断して回収します。1件目に2枠、2件目に25枠あれば、大結晶で合計27枠を選べます。
- 防具・オフハンドの回収では、元の装備欄が空いていれば装着し、埋まっていれば通常インベントリへ戻すよう処理します。
- **キャンセル時には結晶を消費しません**。回収途中の例外が発生した場合は、消費・戻しの結果をゲーム内で確認してください。
- 現在の未回収状況は `/function praeteria/status` で**保管庫件数・枠数・個数**として確認できます。

## 時流素材とその他の特殊アイテム

| 名前 | ID | 入手・用途 |
| --- | --- | --- |
| 時の欠片 | `praeteria:time_shard` | 未来を売る者の死亡時に**1〜3個確定ドロップ**（ドロップ増加で追加個数あり）。時駆けるつるはしの強化素材 |
| 時流インゴット | `praeteria:timeflow_ingot` | 時の欠片9個を3×3配置して製作。時流シリーズの材料 |
| 時送りの杖 | `praeteria:time_wand` | 作業台の**中央に時流インゴット＋左下に棒**（配置指定、Issue #22修正版）。使用で時間追放の飛び道具を放つ |
| 祝福の刻 | `praeteria:blessed_hour` | 多数のバフを発動する再使用可能な道具。詳細は下記 |

### 時送りの杖

**v0.2.7のレシピ：中央に時流インゴット、左下に棒。** 旧レシピ（中央ダイヤ）は無効になりました。

杖の使用で時間魔法弾を発射。命中した**防具未装備のプレイヤーは30秒間スペクテイター化し、移動・視点操作を制限**します。対象がモブの場合は不可視・鈍足・弱体化による疑似追放を適用します。連射間隔は実装上約2秒。**時流防具1部位以上を装備していると時間追放を受けません**。相手のゲームモードなどは解除時に戻す処理がありますが、ほかのアドオンとの競合は未確認です。

### 祝福の刻

**現在のレシピ（v0.2.2 / Issue #3）**：

```text
[ 空き ] [ネザースター] [ 空き ]
[大結晶] [    時計    ] [大結晶]
[インゴット] [インゴット] [インゴット]
```

使用時にインベントリまたは左手から**未来の大結晶1個**を消費し、使用者に次の効果を付与します。**本体は消費されません**。再使用間隔は**5分（プレイヤーごとに記録）**。

| 効果 | レベル | 時間 |
| --- | --- | --- |
| 即時回復 | X | 発動時（加えて体力を最大値へ回復） |
| 衝撃吸収 | V | 60秒 |
| 再生能力 | V | 60秒 |
| 攻撃力上昇 | V | 60秒 |
| 耐性 | III | 60秒 |
| 採掘速度上昇 | V | 60秒 |
| 火炎耐性 | I | 60秒 |
| 水中呼吸 | I | 60秒 |

※ `祝福の刻` の**クラフト**に必要な未来の大結晶2個と、**発動**に必要な未来の大結晶1個は別です。レシピ変更前の「インゴット7＋プラエテリタ＋時計」は現行版では使いません。

詳細な製作一覧は [クラフトレシピ](CRAFTING.md) にあります。

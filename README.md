# Praeterita-Addon
過去を封じ込める。郷愁に浸る。
そして未来の強烈な鮮やかさと息ぐるしさに耐えきれない時、過去を叩き割る。

Minecraft Bedrock Edition向け、時間操作・未来の保管庫・時流装備を追加する開発中アドオンです。

> **開発版 v0.2.2。実機での総合動作テストはまだ完了していません。** 重要なワールドのコピーでテストし、先にバックアップしてください。

## 導入

- `Praeterita_BP` を `development_behavior_packs` に入れます。
- `Praeterita_RP` を `development_resource_packs` に入れます。
- ワールド設定で両方を有効にします。古い同一UUIDの開発用フォルダは残さないでください。
- 内部識別子は既存ワールドの互換性維持のため `praeteria:` を継続使用しています。

### 時間停止の技術的制約

移動は毎ティック位置を固定し、近接攻撃は弱体化させています。飛び道具は射出元が特定できたときに削除します。**Bedrock Script APIで全種類のモブAI・特殊遠距離攻撃を完全無効化できる保証はありません。** スケルトン、ブレイズ、シュルカーなどは実機テストが必要です。

リポジトリにはプレイヤー名・実サーバーのIP・接続認証情報・ローカルパス・テスト時のスクリーンショットを含めません。GitHubの公開リポジトリは検索可能で、アカウント名やコミット著者情報は公開されます。公開前にGitHubのメールプライバシー設定を確認してください。

## 導入

- `Praeterita_BP` を `development_behavior_packs` に入れます。
- `Praeterita_RP` を `development_resource_packs` に入れます。
- ワールド設定で両方を有効にします。古い同一UUIDの開発用フォルダは残さないでください。
- 内部識別子は既存ワールドの互換性維持のため `praeteria:` を継続使用しています。

## v0.2.3 の更新（Issue #5〜#10）

- 時流防具**1部位でも時間追放を無効化**。
- 商人の時間追放は**5秒**、魔法の発射間隔は**6.8秒**。杖による追放は30秒のまま。

- 商人の出現場所を地上・非海洋・フルブロック上に限定。

仕様は**各Issueの最後の採用コメント**に従っています。Minecraft実機・BDSでの総合検証は未完了。

### 時間停止の技術的制約

移動は毎ティック位置を固定し、近接攻撃は弱体化させています。飛び道具は射出元が特定できたときに削除します。**Bedrock Script APIで全種類のモブAI・特殊遠距離攻撃を完全無効化できる保証はありません。** スケルトン、ブレイズ、シュルカーなどは実機テストが必要です。
